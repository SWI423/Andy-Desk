### M5 拆分说明

原 WBS 把记忆做成单任务，实测会有"跑不起来但看不出哪错"的问题，故按可独立验证的粒度拆成 M5a/b/c/d：
M5d（摘要压缩）放到 V1.0，MVP 阶段先不做摘要——先保证"事实不丢"，再谈压缩。

## 五、风险与关键路径

| 风险 | 影响任务 | 缓解 |
|---|---|---|
| 模型工具调用不稳定 | M7 M11 | 提示词写死顺序 + 代码侧校验；关键参数缺失直接拒绝执行 |
| 调度器与 Qt 线程冲突 | M8 M9 | 独立线程 + Qt 信号回主线程 |
| 免费模型长 prompt 注意力差 | M5c M11 | 严格 token 预算；关键信息后置 |
| 记忆检索阈值不适配中文 | M5c | 已实测：embedding-3 中文向量有强公共方向，直接余弦无关句也 0.5+；改用去均值余弦，阈值 0.10 / margin 0.06（ADR-008） |
