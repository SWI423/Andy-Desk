## 一、产品定位

大白是一个运行在 Windows 桌面的 AI 健康陪伴宠物——以电影大白为原型，通过对话和工具调用，主动提醒你作息、记录健康事件、提供医疗科普和情绪疏导，成为长期在场的私人健康管家。

- **是什么**：桌面宠物 + AI 健康助理
- **给谁用**：长时间面对屏幕的学生/开发者本人，未来扩展到家庭儿童
- **解决什么**：健康没人管、情绪没人听、琐事没人记

---

## 二、用户画像

### 主用户：开发者本人（Wendy）
- 大三计算机专业，考研+软考+求职多线作战
- 长时间对着电脑、经常熬夜、颈椎/眼睛不适、压力大
- 日均对话 10-20 轮

### 次用户：弟弟（远程提醒场景）
- 小学生，需要定时提醒写作业、刷牙、眼保健操
- 通过微信接收大白生成的提醒内容

## 三、功能清单（MoSCoW）

### Must（P0 核心，必须做）

| # | 功能 | 验收标准 |
|---|---|---|
| M1 | 桌面宠物窗口 | 开机启动，窗口置顶，可拖动 |
| M2 | AI 对话核心 | 流式输出，延迟 < 3 秒，连续对话不失忆 |
| M3 | 健康事件记录 | 说不适→自动记录到数据库 |
| M4 | 医疗知识库 RAG 检索 | 问健康问题→返回知识库内容 |
| M5 | 健康趋势查询 | 问"最近怎么样"→报近 N 天症状统计 |
| M6 | 记忆与定时提醒 | 记住重要事项，定时弹出提醒 |
| M7 | 久坐/熬夜主动提醒 | 连续 2 小时未操作弹提醒，凌晨 1 点后劝睡 |

### Should（P1 次要，第二阶段）

| # | 功能 | 验收标准 |
|---|---|---|
| S1 | 语音输出 TTS | 回复后自动播放语音 |
| S2 | 语音输入 ASR | 按住说话→转文字 |
| S3 | 情绪识别与疏导 | 用户说"好累"→共情而非建议 |
| S4 | 用户健康画像 | 建议时结合个人基线信息 |
| S5 | 微信代发提醒（人工审查） | 定时生成内容→打开微信→粘贴→用户手动发送 |

### Could（P2 扩展，以后做）

| # | 功能 | 验收标准 |
|---|---|---|
| C1 | 桌面操作工具集 | 打开程序、截屏、打开网页 |
| C2 | MCP 工具接入 | 接入外部 MCP 服务 |
| C3 | 儿童模式 | 切换护眼辅导人设 |
| C4 | 手机版 | Kotlin Android 重写 |

### Won't（本期不做）

- 不做诊断和开处方
- 不做多用户账号体系
- 不做社交广场
- 不做复杂数据可视化仪表盘

## 四、技术选型

| 模块 | 技术 | 用途 | 理由 |
|---|---|---|---|
| 主模型 | 智谱 GLM-4.7-Flash | 对话、工具调用 | 永久免费、无 token 上限、200K 上下文 |
| 向量模型 | 智谱 embedding-3 | 知识库向量化 | 随主模型免费 |
| GUI | PyQt6 | 桌宠窗口、聊天面板 | Python 原生，成熟稳定 |
| 数据库 | SQLite | 记忆、健康记录、提醒 | 零配置，单文件 |
| 定时调度 | APScheduler | 提醒、久坐检测 | 轻量，和 PyQt6 兼容 |
| 微信控制 | wxauto | 打开微信、粘贴内容 | 开源，P2 再接 |
| 日志 | logging | 文件日志 | 内置，按天轮转 |
| 测试 | pytest | 功能测试 | 已装 |
